### 📧 3. Email Spam Detection with Machine Learning

A Machine Learning project that classifies messages as **Spam** or **Ham** using NLP techniques.

**Key Features:**

- Text preprocessing
- Lowercase conversion
- Punctuation and number removal
- Stopword removal
- TF-IDF feature extraction
- Multinomial Naive Bayes
- Logistic Regression
- Confusion Matrix
- Accuracy, Precision, Recall and F1 Score
- WordCloud visualization
- Prediction on unseen messages

**Best Model Performance:**

| Model | Accuracy | Precision | Recall | F1 Score |
|---|---:|---:|---:|---:|
| **Multinomial Naive Bayes** | **96.41%** | **98.92%** | **71.88%** | **83.26%** |
| Logistic Regression | 95.45% | 98.80% | 64.06% | 77.73% |

**Tools & Technologies:**

`Python` `Pandas` `NumPy` `Scikit-learn` `TF-IDF` `NLP` `Matplotlib` `Seaborn` `WordCloud` `Jupyter Notebook`

📁 **Project:** [`Email-Spam-Detection`](./Email-Spam-Detection/)
